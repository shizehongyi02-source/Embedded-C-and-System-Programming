# Embedded C and System Programming

Collection of embedded systems and Linux system programming assignments completed during my Bachelor studies in Autonomy Technologies at Friedrich-Alexander-Universität Erlangen-Nürnberg (FAU).

## Topics Covered

- Embedded C Programming
- AVR Microcontrollers
- LED Control
- Interrupts
- Concurrency and Synchronization
- Power Saving Modes
- Memory Management
- POSIX Processes
- Signals
- Linux System Programming

## Assignments

### blink.c
Implementation of a basic LED blinking application on the SPIcboard.

### snake.c
Snake game implementation using LEDs and button inputs.

### led.c
LED module implementation using AVR I/O ports and modular programming concepts.

### spiel.c
Reaction and hand-eye coordination game using LEDs, buttons and interrupt-driven logic.

### solar.c
Embedded application focusing on interrupts, synchronization and power-saving techniques.

### concat.c
String processing and dynamic memory allocation under Linux.

### printdir.c
Directory traversal and file system operations using POSIX APIs.

### mish.c
Mini shell implementation using POSIX processes and signal handling.

### test-led.c
Testing framework for LED module functionality.

## Technologies

- C
